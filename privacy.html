Privacy Policy

Last updated: 30 October 2026

Kairon is a private, single-user application. It is used only by its owner, to access the owner's own Google account data.

Data accessed

With the owner's consent, Kairon accesses the owner's Google Calendar, Gmail, Tasks, Drive, Contacts, Sheets and Docs to read and manage the owner's own information.

How data is used

Data is used only to provide the owner's personal assistant features (schedules, reminders, email summaries, task management). It is not sold, shared with third parties, or used for advertising.

Storage

The OAuth access token is stored on the owner's private server. Google account data is not stored in any public location.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
